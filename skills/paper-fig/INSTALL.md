# Paper Fig 使用说明

这是从 Presentations 复制并轻量修改的独立技能，用于论文 pipeline、方法框架图、系统架构图及其他可编辑学术插图。技能名称为 `paper-fig`，默认输出单页 PPTX。

## 安装与调用

解压 ZIP，将整个 `paper-fig` 文件夹放入目标 Codex 环境的个人技能目录：设置了 `CODEX_HOME` 时使用其下的 `skills/`，否则使用 `~/.codex/skills/`。保留所有子目录；不要只复制 `SKILL.md`，也不要覆盖原有的 Presentations。由宿主重新发现技能后，在任务中调用 `$paper-fig`。

例如：

> 使用 $paper-fig，根据以下方法描述制作一页可编辑的论文 pipeline。先生成完整设计预览，再参考预览构建 PPTX。方法描述：……

生成预览前会参考 `references/preview_prompt.md`，将画布、布局比例、配色、文字、连线以及各区域所需的图像素材整理成完整绘图 prompt，保存到当前任务的 `work/preview-prompt.md`，方便查看和复用。新设计默认包含有助于解释内容的图像素材，用户要求无图设计时除外。

或：

> 使用 $paper-fig，将附图忠实重建为可编辑 PPTX。保留原图的布局、比例、字体、配色、文字和连线路径。

默认遵循用户的模板或设计。已有重建参考图时直接使用；生成预览后，可针对明显的局部留白失衡、拥挤或错位给出最多 3 条具体建议；修复仅在用户已授权的范围内执行，未授权时保留原预览并继续。之后按选定参考完成重建。仅在用户要求的范围内调整设计，可编辑性不会被视为重新设计的理由。

## 运行环境

适用于提供兼容演示文稿运行时的 Codex 环境。需要 Node.js、Python，以及宿主提供的 `@oai/artifact-tool`；生成整页预览或子图时，还需要可用的图像生成工具。提供参考图且不需要生成新素材时，可以直接进行重建。

技能通过 `load_workspace_dependencies` 或宿主已提供的兼容运行时路径定位依赖，不包含作者电脑的固定路径。执行脚本前，将 `RUNTIME_NODE`、`RUNTIME_NODE_MODULES`、`RUNTIME_BIN_DIR`、`RUNTIME_PYTHON` 设置为接收方自己的路径，并让子进程继承这些环境变量。`SKILL_DIR` 指向安装后的 `paper-fig` 文件夹。

ZIP 包含完整技能文档与辅助脚本，不包含 `@oai/artifact-tool` 运行时、字体、图像生成服务或服务凭证。仅将 ZIP 解压到一个没有这些能力的普通聊天环境，并不能直接生成 PPTX。

## 修改范围

- 修改 `SKILL.md` 的名称、适用范围、运行环境说明和模板入口。
- 在制作流程中加入完整预览、参考重建，以及裁切或每批最多并行生成 4 个独立高清素材。
- 新增 `references/preview_prompt.md`，指导整体绘图 prompt 的具体表达和图像素材规划，不包含固定案例或额外检查流程。
- 参考重建默认忠实保留用户设计，移除原改编版中允许自主优化的宽泛措辞。
- 生成预览后增加一次简短的局部修复建议，不自动改动用户提供或已选定的参考图，不新增报告或强制确认。
- 更新 `agents/openai.yaml` 的显示名称与调用提示。
- `style_guidelines.md`、`references/template_following.md`、实现说明、API 文档与验证脚本均沿用原版；没有添加新的审批或检查流程。

参考基础为 Presentations 26.905.11957。本技能为独立改编版，不会随原插件更新自动改变。
